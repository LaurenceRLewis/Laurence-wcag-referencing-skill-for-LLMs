# SC 3.3.8 — Accessible Authentication (Minimum) (Level AA) ← NEW in WCAG 2.2

## Intent
Authentication processes do not require users to solve a cognitive function test unless an alternative method or assistance is available — so users with cognitive disabilities can authenticate without barriers.

## What is a cognitive function test?
- Memorising a password or PIN
- Transcribing characters from an image (CAPTCHA)
- Solving a puzzle
- Recognising objects in images (image-based CAPTCHA)

## Passes when
- Password field allows paste (password managers can fill it)
- `autocomplete="current-password"` and `autocomplete="username"` are set
- No JavaScript blocking paste (`oncopy`, `onpaste` not suppressed)
- No `autocomplete="off"` on authentication fields
- An alternative authentication method is available alongside any cognitive test (magic link, passkey, biometric)
- Object-recognition CAPTCHA has an audio alternative

## Fails when
- Paste is disabled on password fields
- `autocomplete="off"` on username/password fields prevents password manager use
- The only authentication option is a visual CAPTCHA with no alternative
- Only authentication option is a puzzle or game

## Exceptions at AA (not at AAA)
- Object recognition allowed if an alternative is available
- Personal content recognition (e.g. "identify your pet photo") allowed if an alternative is available

## WCAG 2.2 change
NEW in WCAG 2.2 — did not exist in WCAG 2.1.
