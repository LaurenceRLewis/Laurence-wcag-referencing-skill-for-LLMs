# SC 2.4.13 — Focus Appearance (Level AAA) ← NEW in WCAG 2.2

> **Level AAA — for reference only.** Not required for standard AA conformance.

## Intent
The keyboard focus indicator meets minimum size and contrast requirements — so users with low vision can clearly see which element has focus.

## Requirements
1. The focus indicator area is at least as large as a 2 CSS px perimeter around the unfocused component
2. The colour change between focused and unfocused states has a contrast ratio of at least 3:1 against adjacent colours

## Passes when
A 2px solid outline with ≥ 3:1 contrast against the adjacent background — for example, a 2px `#005fcc` outline on a white background (contrast 8.59:1 ✅).

## Code example

```css
:focus-visible {
  outline: 2px solid #005fcc; /* meets 3:1 against white and most light backgrounds */
  outline-offset: 2px;
}
```

## WCAG 2.2 change
NEW in WCAG 2.2 — did not exist in WCAG 2.1.
