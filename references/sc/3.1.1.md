# SC 3.1.1 — Language of Page (Level A)

## Intent
The default human language of each web page can be programmatically determined — so screen readers select the correct voice, pronunciation engine, and language-specific rendering.

## Passes when
`<html lang="en">` (or the appropriate language code) is present and correct on every page.

## Fails when
- `lang` attribute is missing from `<html>`
- `lang` is set to the wrong language
- `lang` contains an invalid or unsupported code

## Common language codes
`en` (English), `en-AU` (Australian English), `en-GB` (British English), `fr` (French), `de` (German), `es` (Spanish), `ja` (Japanese), `zh` (Chinese), `ar` (Arabic — also set `dir="rtl"`), `pt` (Portuguese).

## Code example
```html
<html lang="en-AU">
```

## WCAG 2.2 change
No change from WCAG 2.1.
