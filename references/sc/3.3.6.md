# SC 3.3.6 — Error Prevention (All) (Level AAA)

> **Level AAA — for reference only.** Not required for standard AA conformance.

## Intent
For all pages requiring user submission, submissions are reversible, checked, or confirmed — stricter than SC 3.3.4 which only covers legal, financial, and data-modifying submissions.

## WCAG 2.2 change
No change from WCAG 2.1.

## Related criteria
- SC 3.3.4 — Error Prevention (Legal, Financial, Data) (Level AA)
