# SC 1.1.1 — Non-text Content (Level A)

## Intent
Provide text alternatives for non-text content so it can be changed into other forms people need, such as large print, braille, speech, symbols, or simpler language.

## Applies to
Images, icons, charts, graphs, infographics, audio, video, CAPTCHA, decorative content, image buttons, and any non-text element that conveys information or serves a function.

## Passes when
- Informative images have descriptive `alt` text conveying the same information as the image
- Functional images (e.g. image buttons, linked images) have `alt` describing the function, not the appearance
- Decorative images use `alt=""` (empty) and/or `aria-hidden="true"`
- Complex images (charts, diagrams, infographics) have a short `alt` plus a long description accessible nearby or via a link
- CAPTCHAs provide a text alternative explaining the purpose, plus an alternative input modality (e.g. audio)
- Icon-only buttons have an accessible name via `aria-label` or visually hidden text

## Fails when
- `alt` attribute is missing entirely from an `<img>`
- `alt` contains the filename (e.g. `alt="image001.jpg"`)
- `alt` says "image of" or "photo of" (redundant — screen readers already announce "image")
- Decorative images have descriptive `alt` text (adds noise for screen reader users)
- Icon-only buttons have no accessible name
- Complex images have only a short `alt` with no long description

## Common mistakes
- Using `alt` to stuff keywords for SEO
- Writing identical `alt` text for multiple unique images
- Forgetting `alt` on linked images (the link then has no accessible name)
- Using `title` attribute instead of `alt` (unreliable across assistive technologies)

## Code examples

```html
<!-- Informative image -->
<img src="chart.png" alt="Bar chart showing sales grew 40% in Q4 2024">

<!-- Decorative image -->
<img src="divider.png" alt="">

<!-- Functional image (linked) -->
<a href="/home">
  <img src="logo.png" alt="Acme Corp — return to homepage">
</a>

<!-- Icon button -->
<button aria-label="Close dialog">
  <svg aria-hidden="true" focusable="false">...</svg>
</button>

<!-- Complex image with long description -->
<figure>
  <img src="org-chart.png" alt="Organisation chart — full description below">
  <figcaption>
    The CEO reports to the Board. Three directors report to the CEO: Finance, Operations, and Technology.
  </figcaption>
</figure>
```
