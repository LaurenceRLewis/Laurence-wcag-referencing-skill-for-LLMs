# SC 1.2.5 — Audio Description (Prerecorded) (Level AA)

## Intent
Provide audio description for all prerecorded video content in synchronised media.

## Applies to
Prerecorded video with audio where visual content conveys information not in the audio track.

## Passes when
An audio description track is available that narrates significant visual information — actions, scene changes, on-screen text, facial expressions — not conveyed in the main audio.

## Fails when
- No audio description track provided
- Text alternative provided instead (acceptable at Level A via SC 1.2.3, but not sufficient for AA)

## WCAG 2.2 change
No change from WCAG 2.1.

## Related criteria
- SC 1.2.3 — Audio Description or Media Alternative (Level A)
- SC 1.2.7 — Extended Audio Description (Level AAA)
