# SC 1.2.7 — Extended Audio Description (Prerecorded) (Level AAA)

> **Level AAA — for reference only.** Not required for standard AA conformance.

## Intent
Where pauses in foreground audio are insufficient to allow audio descriptions, provide extended audio description — the video is paused to allow the description to be read before resuming.

## Passes when
Video can be paused during audio description to allow extended narration of complex visual content.

## WCAG 2.2 change
No change from WCAG 2.1.
