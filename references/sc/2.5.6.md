# SC 2.5.6 — Concurrent Input Mechanisms (Level AAA)

> **Level AAA — for reference only.** Not required for standard AA conformance.

## Intent
Content does not restrict use of input modalities available on the platform, except where essential — so users can switch freely between keyboard, mouse, touch, and other inputs.

## Passes when
Users can use any available input method at any time — switching from keyboard to touch mid-session without the application restricting or disabling any input type.

## Fails when
A web app detects touch input and disables keyboard access, or detects mouse and disables touch.

## WCAG 2.2 change
No change from WCAG 2.1.
