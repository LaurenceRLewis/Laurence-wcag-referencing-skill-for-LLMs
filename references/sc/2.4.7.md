# SC 2.4.7 — Focus Visible (Level AA)

## Intent
Any keyboard-operable user interface has a visible keyboard focus indicator — so keyboard users can see which element currently has focus.

## Passes when
When any interactive element receives keyboard focus, a visible focus indicator is present (outline, ring, underline, colour change, or other visual treatment).

## Fails when
- `outline: none` or `outline: 0` applied globally with no replacement focus style
- Focus indicator exists but is invisible due to colour contrast (see SC 1.4.11)
- Custom focus styles are removed via `*:focus { outline: none }`

## Note
SC 2.4.7 only requires focus to be *visible* — not a specific size or contrast level. SC 2.4.11 (AA, new in 2.2) adds that focus must not be entirely obscured. SC 2.4.13 (AAA) adds size and contrast requirements for the focus indicator itself.

## Code example

```css
/* Do not do this without a replacement */
:focus { outline: none; }

/* Acceptable replacement */
:focus-visible {
  outline: 2px solid #005fcc;
  outline-offset: 2px;
}
```

## WCAG 2.2 change
No change from WCAG 2.1 — but SC 2.4.11 and 2.4.13 (new in 2.2) extend focus requirements.
