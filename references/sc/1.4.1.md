# SC 1.4.1 — Use of Colour (Level A)

## Intent
Colour is not used as the only visual means of conveying information, indicating an action, prompting a response, or distinguishing a visual element.

## Applies to
Any UI where colour alone communicates meaning — error states, required fields, charts, links, status indicators.

## Passes when
- Required fields indicated by asterisk AND label text, not colour alone
- Error states indicated by an icon or text label in addition to red colouring
- Charts use both colour and pattern, texture, or direct labelling to distinguish data series
- Links are distinguishable from surrounding body text by underline or another non-colour indicator (not colour alone)

## Fails when
- "Fields marked in red are required" — colour alone identifies required fields
- "The green bars show sales, the blue bars show costs" — colour alone distinguishes chart data with no other differentiator
- Links styled to differ from body text only by colour with no underline or other indicator
- Status indicators (online/offline, pass/fail) use only colour with no text or icon

## Code examples

```html
<!-- Fail: colour-only error -->
<input style="border-color: red">

<!-- Pass: colour + icon + text -->
<input aria-invalid="true" aria-describedby="err">
<span id="err">
  <svg aria-hidden="true"><!-- error icon --></svg>
  Email address is required
</span>
```
