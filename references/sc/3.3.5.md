# SC 3.3.5 — Help (Level AAA)

> **Level AAA — for reference only.** Not required for standard AA conformance.

## Intent
Context-sensitive help is available — so users can get assistance without leaving the current task.

## Passes when
- Help text or tooltips provided in context of form fields
- Links to relevant help articles provided near complex tasks
- Inline explanations of form requirements available on demand

## WCAG 2.2 change
No change from WCAG 2.1.
