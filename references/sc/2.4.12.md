# SC 2.4.12 — Focus Not Obscured (Enhanced) (Level AAA) ← NEW in WCAG 2.2

> **Level AAA — for reference only.** Not required for standard AA conformance.

## Intent
When a UI component receives keyboard focus, no part of it is hidden by author-created content — stricter than SC 2.4.11 which allows partial obscuring.

## Passes when
The entire focused component is visible — no part of it is covered by sticky headers, floating elements, or overlays.

## WCAG 2.2 change
NEW in WCAG 2.2 — did not exist in WCAG 2.1.

## Related criteria
- SC 2.4.11 — Focus Not Obscured (Minimum) (Level AA — allows partial obscuring)
