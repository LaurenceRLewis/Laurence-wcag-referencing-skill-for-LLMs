# SC 2.5.8 — Target Size (Minimum) (Level AA) ← NEW in WCAG 2.2

## Intent
The size of pointer input targets is at least 24×24 CSS pixels, or the target has sufficient spacing so the combined area meets 24×24 — so users with motor impairments can reliably activate interactive elements.

## The spacing rule
If a target is smaller than 24×24px, the target plus its offset (spacing from adjacent targets) must together cover a 24×24 CSS pixel area. Adequate padding around small targets can satisfy this criterion.

## Passes when
- A 32×32px icon button ✅ (exceeds 24×24)
- A 16×16px icon button with 8px spacing on each side ✅ (spacing + target = 24px circle)
- Text links in body copy ✅ (exempt — inline exception)

## Fails when
- A 16×16px icon button with no padding or spacing ❌
- A close "×" that is 12×12px with 2px margin ❌
- Navigation links at 20px tall with no padding ❌

## Exceptions
- **Inline:** Links within a run of text (size determined by line height)
- **User agent:** Size set by the browser, not modified by the author
- **Essential:** A specific size is required by the information (e.g. a small pin on a map)
- **Equivalent:** Another control on the same page performs the same function and meets the target size

## WCAG 2.2 change
NEW in WCAG 2.2 — did not exist in WCAG 2.1. SC 2.5.5 (Level AAA) requires the larger 44×44px.
