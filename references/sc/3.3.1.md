# SC 3.3.1 — Error Identification (Level A)

## Intent
If an input error is automatically detected, the item in error is identified and the error is described to the user in text — so users understand what went wrong and where.

## Passes when
- The specific field with an error is identified ("Email address is required")
- The error is described in text, not colour alone
- `aria-invalid="true"` is set on the erroneous field
- The error message is associated with the field via `aria-describedby`

## Fails when
- Only a red border indicates an error — colour alone (also fails SC 1.4.1)
- Generic error "Please fix the errors above" without identifying specific fields
- Error message exists but is not programmatically associated with the input

## Code example

```html
<label for="email">Email address</label>
<input
  type="email"
  id="email"
  aria-invalid="true"
  aria-describedby="email-error"
>
<span id="email-error" role="alert">
  Enter a valid email address, for example name@example.com
</span>
```
