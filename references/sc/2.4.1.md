# SC 2.4.1 — Bypass Blocks (Level A)

## Intent
A mechanism exists to bypass blocks of content that are repeated on multiple pages, so keyboard and screen reader users can navigate efficiently without tabbing through the same navigation on every page.

## Passes when
- A skip navigation link is provided at the top of each page that jumps to the main content, OR
- Landmark regions (`<main>`, `<nav>`, `<header>`) allow screen reader users to jump between sections, OR
- Both a skip link and landmarks are provided (best practice)

## Fails when
- No skip link and no landmark regions — keyboard users must Tab through the entire navigation on every page
- Skip link exists but is not keyboard focusable (hidden with `display: none` instead of visually hidden)

## Skip link pattern

```html
<a href="#main-content" class="skip-link">Skip to main content</a>
<!-- navigation here -->
<main id="main-content">
  <!-- page content -->
</main>
```

```css
.skip-link {
  position: absolute;
  left: -9999px;
}
.skip-link:focus {
  left: 0;
  /* make visible on focus */
}
```

No change from WCAG 2.1.
