# SC 2.5.2 — Pointer Cancellation (Level A)

## Intent
For single-pointer actions, accidental activation is preventable — so users who accidentally touch or click an element can cancel before the action fires.

## The four ways to satisfy this
At least one of the following must apply:
1. **No down-event trigger** — the action does not fire on the pointer down event (mousedown, touchstart)
2. **Abort or undo** — the action can be aborted before completion or undone after
3. **Up reversal** — the up-event reverses any action triggered by the down-event
4. **Essential** — triggering on the down-event is essential (e.g. a piano key that must sound immediately)

## Passes when
- Buttons activate on mouseup/pointerup, not mousedown — users can drag away to cancel
- A drag-and-drop action can be abandoned by releasing outside the target

## Fails when
- An action fires immediately on mousedown/touchstart with no cancellation
- Clicking an element triggers an irreversible action on the down event

## WCAG 2.2 change
No change from WCAG 2.1.
