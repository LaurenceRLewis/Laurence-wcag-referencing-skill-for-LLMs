# SC 1.4.11 — Non-text Contrast (Level AA)

## Intent
The visual presentation of UI components and graphical objects has at least 3:1 contrast against adjacent colours — so users with low vision can perceive the boundaries and states of interface elements.

## Applies to
- UI component boundaries (form field borders, checkbox outlines, button outlines)
- UI component states (focus indicators, selected states, checked checkboxes, toggle states)
- Informational graphical objects (chart lines, icons that convey information, custom bullet styles)

## Passes when
The visual boundary or state indicator of a component has ≥ 3:1 contrast against adjacent background colour.

## Fails when
- Form field border is `#ccc` on white — 1.6:1 contrast ❌
- Checkbox border is light grey — below 3:1 ❌
- Focus indicator has < 3:1 contrast against the background ❌
- An icon conveying meaning (not decorative) has < 3:1 contrast ❌

## Exempt
- Disabled/inactive components
- Decorative graphical elements

## Common values
- `#949494` on white = 3.03:1 ✅ (just passes)
- `#767676` on white = 4.48:1 ✅
- `#bbbbbb` on white = 1.9:1 ❌

## WCAG 2.2 change
No change from WCAG 2.1. Note: SC 2.4.11 (new in 2.2) adds requirements about focus indicators not being obscured.
