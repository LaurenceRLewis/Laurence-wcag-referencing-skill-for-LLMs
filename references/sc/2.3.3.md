# SC 2.3.3 — Animation from Interactions (Level AAA)

> **Level AAA — for reference only.** Not required for standard AA conformance.

## Intent
Motion animation triggered by user interaction can be disabled, unless the animation is essential to the function.

## Passes when
- The `prefers-reduced-motion` CSS media query is respected and non-essential animations are disabled when the user has requested reduced motion
- No non-essential motion animation is present

## Code example

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## WCAG 2.2 change
No change from WCAG 2.1.
