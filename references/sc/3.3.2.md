# SC 3.3.2 — Labels or Instructions (Level A)

## Intent
Labels or instructions are provided when content requires user input — so users understand what is expected before they begin entering data.

## Passes when
- Every form input has a visible and programmatically associated `<label>`
- Required fields are indicated (text, asterisk with legend, `aria-required`)
- Format constraints are communicated before input ("Date: DD/MM/YYYY")
- Placeholder text supplements but does not replace a visible label

## Fails when
- Placeholder text is the only label — it disappears on input and is not reliably exposed to assistive technology
- Required fields have no indicator
- A phone number field has no format hint and accepts only one specific format

## Code example

```html
<!-- Correct -->
<label for="dob">Date of birth</label>
<input type="text" id="dob" placeholder="DD/MM/YYYY"
  aria-describedby="dob-hint">
<span id="dob-hint">Enter in format DD/MM/YYYY</span>

<!-- Fail: placeholder only -->
<input type="text" placeholder="Date of birth (DD/MM/YYYY)">
```
