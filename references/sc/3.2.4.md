# SC 3.2.4 — Consistent Identification (Level AA)

## Intent
Components with the same functionality are identified consistently throughout a set of pages — so users who learn to identify a component on one page can find and use it on other pages.

## Passes when
- A search field is always labelled "Search" across all pages
- A print icon always has the same accessible name ("Print this page")
- A "Close" button is always labelled "Close" across all dialogs

## Fails when
- A search field is labelled "Search" on some pages and "Find" on others
- A close button is labelled "Close" in some dialogs and "Dismiss" in others
- The same icon means different things on different pages

## WCAG 2.2 change
No change from WCAG 2.1.
