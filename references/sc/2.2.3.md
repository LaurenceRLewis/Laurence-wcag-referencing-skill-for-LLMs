# SC 2.2.3 — No Timing (Level AAA)

> **Level AAA — for reference only.** Not required for standard AA conformance.

## Intent
Timing is not an essential part of any event or activity (except real-time events and essential situations) — stricter than SC 2.2.1 which allows adjustable time limits.

## WCAG 2.2 change
No change from WCAG 2.1.
