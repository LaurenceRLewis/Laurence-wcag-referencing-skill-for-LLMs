# SC 1.4.4 — Resize Text (Level AA)

## Intent
Text can be resized up to 200% without loss of content or functionality, without requiring assistive technology — so users who need larger text can use browser zoom.

## Passes when
- Browser text zoom to 200% does not cause text to be clipped, truncated, or overlap to the point of losing content or functionality
- All content and functionality remains available at 200% zoom

## Fails when
- Fixed pixel font sizes prevent browser zoom from scaling text
- `overflow: hidden` clips text at zoom levels above 100%
- Content or buttons disappear at 200% zoom
- Text overlaps other text or elements making it unreadable

## Best practice
Use relative units (`rem`, `em`, `%`) rather than fixed `px` for font sizes. This allows browser text-size preferences to scale content appropriately.

## Test method
Set browser text zoom to 200% (not page zoom — text zoom only, where supported). Verify all content is readable and all functionality is operable.

## WCAG 2.2 change
No change from WCAG 2.1.
