# SC 2.5.5 — Target Size (Enhanced) (Level AAA)

> **Level AAA — for reference only.** Not required for standard AA conformance.

## Intent
The size of pointer input targets is at least 44×44 CSS pixels — so users with motor impairments can reliably activate interactive elements.

## Exceptions
- Inline links within a run of text
- Target size determined by the user agent (browser default)
- Essential presentation

## Note
SC 2.5.8 (Level AA, new in WCAG 2.2) is the standard AA requirement at 24×24px. This AAA criterion requires the larger 44×44px.

## WCAG 2.2 change
No change from WCAG 2.1.
