# SC 1.2.3 — Audio Description or Media Alternative (Prerecorded) (Level A)

## Intent
Provide audio description or a full text alternative for prerecorded synchronised media so blind users can access visual content not conveyed in the audio.

## Applies to
Prerecorded video with audio where visual content conveys information not available in the audio track.

## Passes when
- An audio description track is provided that describes significant visual content, OR
- A full text alternative is provided describing all visual and audio content

## Note
SC 1.2.5 (Level AA) requires the audio description specifically — this SC (Level A) allows a text alternative as a fallback. If targeting AA, SC 1.2.5 takes precedence.

## Fails when
- Visual-only information (text on screen, demonstrations, facial expressions conveying meaning) has no audio description or text alternative

## WCAG 2.2 change
No change from WCAG 2.1.

## Related criteria
- SC 1.2.5 — Audio Description (Prerecorded) (Level AA — stricter)
- SC 1.2.1 — Audio-only and Video-only
