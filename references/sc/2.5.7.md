# SC 2.5.7 — Dragging Movements (Level AA) ← NEW in WCAG 2.2

## Intent
All functionality that uses a dragging movement can also be achieved with a single pointer without dragging — so users who cannot perform dragging gestures (motor disabilities, switch access, voice control) can still complete all tasks.

## Applies to
Drag-and-drop lists, range sliders, kanban boards, file upload drop zones, sortable tables, reorderable items.

## Passes when
- Drag-and-drop kanban card also has a "Move to column" button or menu
- Range slider can be positioned by clicking anywhere on the track (not only by dragging the thumb)
- Sortable list has up/down arrow buttons for reordering
- File upload drop zone also has a standard file picker button

## Fails when
- Reordering items is only possible by dragging with no button/keyboard alternative
- Slider thumb can only be moved by click-drag, not by clicking a track position

## Exception
Dragging is essential to the function and cannot be abstracted — e.g. a freehand drawing canvas.

## WCAG 2.2 change
NEW in WCAG 2.2 — did not exist in WCAG 2.1.

- SC 2.1.1 — Keyboard
- SC 2.5.1 — Pointer Gestures
