# SC 2.5.4 — Motion Actuation (Level A)

## Intent
Functionality triggered by device motion (shaking, tilting) or user motion (detected by camera) can also be operated by UI components, and the motion response can be disabled — so users who mount devices or have tremors are not excluded.

## Passes when
- Shake-to-undo has a UI button alternative
- Tilt-to-scroll has an alternative input method
- Motion control can be turned off independently of system settings

## Fails when
- The only way to trigger a feature is device motion with no UI alternative
- Motion response cannot be disabled, causing involuntary activations for users with tremors

## Exception
Motion essential to the function and cannot be done via user interface — e.g. a step counter where the motion detection is the product.

## WCAG 2.2 change
No change from WCAG 2.1.
