# SC 3.2.5 — Change on Request (Level AAA)

> **Level AAA — for reference only.** Not required for standard AA conformance.

## Intent
Changes of context are only initiated by user request, or a mechanism is available to turn off such changes — stricter than SC 3.2.2, which allows changes with prior warning.

## Passes when
Context changes only occur when the user explicitly requests them (e.g. clicking a link or button), with no automatic redirects or page changes.

## WCAG 2.2 change
No change from WCAG 2.1.
