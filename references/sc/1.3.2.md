# SC 1.3.2 — Meaningful Sequence (Level A)

## Intent
When the sequence in which content is presented affects its meaning, the correct reading sequence can be programmatically determined — so screen readers and other assistive technologies present content in the right order.

## Applies to
Any content where visual layout order differs from the logical reading order, especially CSS-positioned content, multi-column layouts, and grid-based designs.

## Passes when
The DOM order reflects the logical reading sequence — when CSS is disabled or ignored, the content still makes sense and flows correctly.

## Fails when
- CSS absolute positioning places content visually before its DOM position, creating a mismatch between visual and programmatic order
- A sidebar appearing visually first in a two-column layout comes after the main content in the DOM, or vice versa, causing confusion when linearised

## Test method
Disable CSS and read the page linearly — does the content still make sense in that order?

## WCAG 2.2 change
No change from WCAG 2.1.
