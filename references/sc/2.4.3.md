# SC 2.4.3 — Focus Order (Level A)

## Intent
Focusable components receive focus in an order that preserves meaning and operability — so keyboard users navigate content in a logical sequence.

## Passes when
- Tab order follows the logical reading sequence (top to bottom, left to right in LTR layouts)
- Dynamically inserted content (modals, alerts, expanded sections) receives focus in a logical position
- Focus does not jump unpredictably

## Fails when
- `tabindex` values > 0 create an unintuitive tab order
- A modal appears visually but focus remains on the content behind it
- Dynamically inserted content is appended to the end of the DOM but logically appears earlier in the page
- Focus jumps to an unexpected location after a user action

## Best practice
Never use `tabindex` values greater than 0. Rely on DOM order for the natural focus sequence. Use `tabindex="0"` to add custom elements to the tab order, and `tabindex="-1"` only for programmatic focus management.

## WCAG 2.2 change
No change from WCAG 2.1.
