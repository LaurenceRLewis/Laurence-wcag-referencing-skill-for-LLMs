# SC 1.4.10 — Reflow (Level AA)

## Intent
Content can be presented without horizontal scrolling or loss of information at a viewport width equivalent to 320 CSS pixels — the equivalent of a 1280px viewport at 400% zoom.

## Applies to
All web content except content that requires two-dimensional layout to be usable (data tables, maps, diagrams, video, games).

## Passes when
- At 320px equivalent width, all content and functionality is available without horizontal scrolling
- Content reflows to a single column
- No content is hidden or removed at this width

## Fails when
- Fixed-width layouts cause horizontal scrolling at 320px equivalent
- Content is hidden or removed at narrow widths
- Text overflows its container and is clipped

## Test method
Set browser zoom to 400% on a 1280px-wide viewport (equivalent to a 320px viewport). Verify no horizontal scrolling is required for content (excluding exempt content types).

## Exempt content types
- Data tables (two-dimensional data)
- Maps
- Diagrams
- Video
- Games
- Toolbars with many buttons

## WCAG 2.2 change
No change from WCAG 2.1.
