# SC 3.3.9 — Accessible Authentication (Enhanced) (Level AAA) ← NEW in WCAG 2.2

> **Level AAA — for reference only.** Not required for standard AA conformance.

## Intent
Authentication processes do not require solving a cognitive function test at any step — no exceptions. Stricter than SC 3.3.8, which allows object recognition and personal content recognition if alternatives exist.

## Passes when
Authentication requires no cognitive test of any kind — pure alternatives such as passkeys, magic links, or biometrics are used throughout.

## WCAG 2.2 change
NEW in WCAG 2.2 — did not exist in WCAG 2.1.

## Related criteria
- SC 3.3.8 — Accessible Authentication (Minimum) (Level AA — allows some exceptions)
