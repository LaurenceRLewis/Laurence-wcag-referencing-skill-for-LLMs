# SC 2.4.5 — Multiple Ways (Level AA)

## Intent
More than one way is available to locate a page within a set of pages — so users can find content using whichever method suits their ability or preference.

## Passes when
At least two of the following are provided:
- Navigation menu
- Site search
- Site map
- Table of contents
- Links between related pages

## Fails when
- Only a single navigation path exists to reach each page
- Single-page apps with no search or alternative navigation to reach specific views

## Exception
A page that is a step in a process (e.g. step 2 of a checkout) is exempt — it only makes sense in the context of the process.

## WCAG 2.2 change
No change from WCAG 2.1.
