# SC 3.3.3 — Error Suggestion (Level AA)

## Intent
If an input error is detected and suggestions for correction are known, the suggestions are provided to the user — so users understand not just that there is an error, but how to fix it.

## Passes when
- "Email format is invalid. Enter in format: name@example.com"
- "Password must be at least 8 characters and include one number"
- Field-specific guidance is provided alongside the error

## Fails when
- Error says "Invalid input" with no guidance on what is valid
- Format error with no example or correction hint

## Exception
Security-sensitive fields where providing a suggestion would compromise security:
- Password fields — no suggestion for what the correct password is
- CAPTCHAs — no answer given

## WCAG 2.2 change
No change from WCAG 2.1.
