# SC 2.4.9 — Link Purpose (Link Only) (Level AAA)

> **Level AAA — for reference only.** Not required for standard AA conformance.

## Intent
The purpose of each link can be identified from the link text alone — stricter than SC 2.4.4 which allows surrounding context to clarify link purpose.

## Passes when
Every link's purpose is clear from its text alone, without needing to read surrounding content.

## Fails when
"Read more" or "Download" without additional accessible text, even if surrounding context makes the purpose clear.

## WCAG 2.2 change
No change from WCAG 2.1.

## Related criteria
- SC 2.4.4 — Link Purpose (In Context) (Level A — allows context)
