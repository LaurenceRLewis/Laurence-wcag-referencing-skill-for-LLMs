# SC 2.5.1 — Pointer Gestures (Level A)

## Intent
All functionality that uses multipoint or path-based gestures (pinch-to-zoom, swipe, draw) can also be achieved with a single pointer without a gesture — so users who cannot perform complex gestures can still access all features.

## Passes when
- Map zoom available via +/− buttons as well as pinch-to-zoom
- Carousel navigable by previous/next buttons as well as swipe
- Freehand signature field has a typed text alternative

## Fails when
- Swipe is the only way to navigate a carousel with no button alternative
- Pinch-zoom required with no button alternative

## Exception
Multipoint or path-based gestures essential to the function — e.g. a freehand drawing app where the path is the product itself.

## WCAG 2.2 change
No change from WCAG 2.1.
