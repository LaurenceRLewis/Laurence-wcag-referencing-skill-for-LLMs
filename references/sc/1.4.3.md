# SC 1.4.3 — Contrast (Minimum) (Level AA)

## Intent
Text and images of text have a contrast ratio sufficient for users with moderately low vision to read without contrast-enhancing assistive technology.

## Requirements

| Text type | Minimum contrast ratio |
|---|---|
| Normal text (< 18pt / < 14pt bold) | 4.5:1 |
| Large text (≥ 18pt or ≥ 14pt bold) | 3:1 |
| Logotypes | Exempt |
| Decorative text with no informational value | Exempt |
| Inactive/disabled UI components | Exempt |

## Passes when
Contrast ratio between text colour and background colour meets or exceeds the threshold for the text size.

## Fails when
- Body text at 4.2:1 contrast (below 4.5:1)
- Grey placeholder text below 4.5:1 (placeholder text is not exempt, despite common assumption)
- Text over images where the background is variable and some areas fall below the threshold

## How to calculate
Contrast ratio = (L1 + 0.05) / (L2 + 0.05) where L1 is the relative luminance of the lighter colour and L2 is the relative luminance of the darker colour.

Use a contrast analyser tool rather than calculating manually.

## Common failing combinations
- `#767676` on `#ffffff` = 4.48:1 ❌ (just below 4.5:1)
- `#949494` on `#ffffff` = 3.03:1 ❌
- `#595959` on `#ffffff` = 7.0:1 ✅
- `#767676` on `#f5f5f5` = lower than on white ❌

## WCAG 2.2 change
No change from WCAG 2.1. Note: WCAG 3.0 will replace this with the APCA model, but WCAG 2.2 retains the existing formula.
