# SC 3.2.3 — Consistent Navigation (Level AA)

## Intent
Navigation mechanisms that appear on multiple pages occur in the same relative order each time they are repeated — so users can predict where to find navigation and develop consistent mental models.

## Passes when
- Site-wide navigation appears in the same position and same order on every page
- Breadcrumbs, search, and utility links appear consistently across pages

## Fails when
- Primary navigation moves to a different location on interior pages
- Navigation items appear in a different order on some pages without user action

## Note
This applies to the *relative order* of repeated items. Adding page-specific items is acceptable — the shared items just must retain their relative order. Users themselves can reorder navigation (e.g. customisable dashboards) without violating this criterion.

## WCAG 2.2 change
No change from WCAG 2.1.
