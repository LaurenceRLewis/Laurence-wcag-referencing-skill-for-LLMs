# SC 2.1.4 — Character Key Shortcuts (Level A)

## Intent
If keyboard shortcuts using only a single character key (letter, number, punctuation, or symbol) are implemented, users can turn them off, remap them, or ensure they only activate when the relevant component has focus.

## Why it matters
Speech input users may inadvertently trigger shortcuts while dictating — saying a word that matches a shortcut key can cause unexpected actions.

## Passes when
- Single-character shortcuts can be turned off entirely, OR
- Single-character shortcuts can be remapped to include a modifier key (Ctrl, Alt, etc.), OR
- Single-character shortcuts only activate when the relevant component has focus (not globally)

## Fails when
- A single-character shortcut fires globally and cannot be turned off or remapped
- A web application uses `j`/`k` for navigation globally with no way to disable

## Exception
Shortcuts only active when a component has focus (e.g. Arrow keys within a listbox) do not need a remapping mechanism.

## WCAG 2.2 change
No change from WCAG 2.1.
