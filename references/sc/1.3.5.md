# SC 1.3.5 — Identify Input Purpose (Level AA)

## Intent
The purpose of form fields that collect personal information can be programmatically determined, enabling browsers and assistive technologies to autofill, present custom icons, or adapt the interface.

## Applies to
Form inputs that collect personal information — name, email, address, phone, payment details, etc.

## Passes when
The `autocomplete` attribute is set to the correct token for each personal data field:
- `autocomplete="given-name"` for first name
- `autocomplete="family-name"` for last name
- `autocomplete="email"` for email address
- `autocomplete="tel"` for phone number
- `autocomplete="street-address"` for address
- `autocomplete="postal-code"` for postcode/zip
- `autocomplete="cc-number"` for credit card number
- `autocomplete="current-password"` for login password
- `autocomplete="new-password"` for new/changed password

## Fails when
- Personal data inputs lack `autocomplete` attributes
- `autocomplete="off"` used on personal data fields without a security reason

## Code example

```html
<label for="fname">First name</label>
<input type="text" id="fname" autocomplete="given-name">

<label for="email">Email</label>
<input type="email" id="email" autocomplete="email">
```
