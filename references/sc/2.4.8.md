# SC 2.4.8 — Location (Level AAA)

> **Level AAA — for reference only.** Not required for standard AA conformance.

## Intent
Information about the user's location within a set of pages is available — so users can orient themselves within the site structure.

## Passes when
- Breadcrumb navigation is provided
- Site map highlights the current page
- Navigation menu indicates the current section

## WCAG 2.2 change
No change from WCAG 2.1.
