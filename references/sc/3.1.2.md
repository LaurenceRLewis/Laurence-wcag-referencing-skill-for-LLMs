# SC 3.1.2 — Language of Parts (Level AA)

## Intent
The human language of each passage or phrase that differs from the page language can be programmatically determined — so screen readers switch to the appropriate voice for inline foreign-language content.

## Passes when
Inline content in a different language uses the `lang` attribute:
```html
<p>The menu includes <span lang="fr">crème brûlée</span>.</p>
```

## Fails when
A French quotation on an English page has no `lang="fr"`, so a screen reader reads it with an English voice.

## Exceptions
- Proper names
- Technical terms used across languages (e.g. "JavaScript")
- Words that are part of the vernacular of the surrounding text (e.g. "café" used in English text)

## WCAG 2.2 change
No change from WCAG 2.1.
