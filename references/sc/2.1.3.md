# SC 2.1.3 — Keyboard (No Exception) (Level AAA)

> **Level AAA — for reference only.** Not required for standard AA conformance.

## Intent
All functionality is operable via keyboard with no exceptions — stricter than SC 2.1.1, which allows an exception for path-dependent inputs (freehand drawing, handwriting).

## WCAG 2.2 change
No change from WCAG 2.1.

## Related criteria
- SC 2.1.1 — Keyboard (Level A — allows path-dependent exceptions)
