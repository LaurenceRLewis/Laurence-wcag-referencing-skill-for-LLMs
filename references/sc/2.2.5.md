# SC 2.2.5 — Re-authenticating (Level AAA)

> **Level AAA — for reference only.** Not required for standard AA conformance.

## Intent
When an authenticated session expires, users can continue after re-authenticating without losing any data they had entered.

## Passes when
Form data and user input is preserved across session re-authentication so users do not lose work when a session expires.

## WCAG 2.2 change
No change from WCAG 2.1.

## Related criteria
- SC 3.3.8 — Accessible Authentication
