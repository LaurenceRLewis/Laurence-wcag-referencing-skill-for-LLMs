# SC 3.2.2 — On Input (Level A)

## Intent
Changing the setting of a UI component does not automatically cause a context change unless the user has been advised in advance — so users are not unexpectedly navigated or redirected when interacting with form controls.

## Passes when
- A country selector redirects to a country-specific page, but users are warned this will happen before the control is used
- Selecting a radio button updates a price display on the same page (not a context change)
- A "Go" button next to a `<select>` initiates navigation after selection

## Fails when
- Selecting a value from a `<select>` immediately redirects the page without warning
- Checking a checkbox causes a page reload without prior warning
- Changing a radio button submits a form automatically

## WCAG 2.2 change
No change from WCAG 2.1.
