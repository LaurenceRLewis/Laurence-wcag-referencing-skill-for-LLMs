# SC 1.4.13 — Content on Hover or Focus (Level AA)

## Intent
Where additional content appears when an element receives pointer hover or keyboard focus (tooltips, sub-menus, popups), that content must meet three requirements so users can perceive and interact with it.

## The three requirements

| Requirement | What it means |
|---|---|
| **Dismissible** | User can dismiss the content without moving focus or hover (e.g. Escape key closes the tooltip) |
| **Hoverable** | User can move the pointer over the triggered content without it disappearing |
| **Persistent** | Content stays visible until focus or hover is moved away, user dismisses it, or the information is no longer valid |

## Passes when
- Tooltip appears on hover/focus
- Tooltip stays visible when the pointer moves over it
- Tooltip can be dismissed with Escape
- Tooltip remains until the user moves focus/hover away

## Fails when
- Tooltip disappears as soon as the pointer moves toward it (not hoverable)
- Tooltip cannot be dismissed with Escape (not dismissible)
- Tooltip disappears after a short timeout while the user is still reading it (not persistent)

## Exception
Native browser tooltips (via the `title` attribute) are handled by the user agent and are exempt — the author cannot control their behaviour.

## Code pattern

```javascript
// Ensure tooltip stays open when pointer moves over it
tooltipTrigger.addEventListener('mouseenter', showTooltip);
tooltipContent.addEventListener('mouseenter', keepTooltipOpen);
tooltipTrigger.addEventListener('mouseleave', hideTooltipAfterDelay);
tooltipContent.addEventListener('mouseleave', hideTooltip);

// Dismiss on Escape
document.addEventListener('keydown', (e) => {
  if (e.key === 'Escape') hideTooltip();
});
```
