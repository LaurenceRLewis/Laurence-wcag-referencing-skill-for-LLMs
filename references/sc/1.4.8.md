# SC 1.4.8 — Visual Presentation (Level AAA)

> **Level AAA — for reference only.** Not required for standard AA conformance.

## Intent
For blocks of text, users can select foreground and background colours, width is no more than 80 characters, text is not fully justified, line height is at least 1.5× the font size within paragraphs, and text can be resized to 200% without requiring horizontal scrolling.

## The five requirements
1. Foreground and background colours can be selected by the user
2. Width is no more than 80 characters or glyphs
3. Text is not fully justified (not aligned to both left and right margins)
4. Line spacing within paragraphs is at least 1.5× the font size; spacing between paragraphs is at least 1.5× the line spacing
5. Text can be resized up to 200% without requiring the user to scroll horizontally

## WCAG 2.2 change
No change from WCAG 2.1.
