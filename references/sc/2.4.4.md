# SC 2.4.4 — Link Purpose (In Context) (Level A)

## Intent
The purpose of each link can be determined from the link text alone, or from the link text together with its programmatically determined context — so screen reader users understand where a link goes without reading surrounding content.

## Context allowed
- The same sentence or paragraph as the link
- The same list item
- The same table cell or associated table header

## Passes when
- "Download the 2024 Annual Report (PDF)" — clear from link text alone
- A "Read more" link within a product card where the card heading provides context
- `aria-label` or `aria-labelledby` provides a descriptive accessible name overriding the visible text

## Fails when
- "Click here", "Read more", "Learn more" with no additional context or accessible label
- Multiple "Download" links on the same page going to different files
- "Here" used as link text ("Click here for more information")

## Code patterns

```html
<!-- Fail -->
<a href="/report.pdf">Read more</a>

<!-- Pass: descriptive text -->
<a href="/report.pdf">Download the 2024 Annual Report (PDF, 2MB)</a>

<!-- Pass: aria-label adds context -->
<a href="/report.pdf" aria-label="Download the 2024 Annual Report (PDF)">Read more</a>

<!-- Pass: visually hidden text -->
<a href="/report.pdf">Read more <span class="visually-hidden">about the 2024 Annual Report</span></a>
```

## WCAG 2.2 change
No change from WCAG 2.1.
