# SC 4.1.2 — Name, Role, Value (Level A)

## Intent
For all UI components, the name and role can be programmatically determined; states, properties, and values that can be set by the user can be programmatically set; and changes are notified to assistive technologies.

## The three parts

### 1 — Name
Every interactive element must have an accessible name:

| Element | How to provide the name |
|---|---|
| `<button>` | Text content, `aria-label`, or `aria-labelledby` |
| `<input>` | Associated `<label>`, `aria-label`, or `aria-labelledby` |
| Icon button | `aria-label` on the `<button>` |
| `<a>` | Text content or `aria-label` |
| Image link | `alt` on the `<img>` |
| `<select>` | Associated `<label>` |
| Custom widget | `aria-label` or `aria-labelledby` |

### 2 — Role
Every interactive element must expose the correct role:
- Use native HTML elements where possible — they have implicit roles
- Custom widgets require explicit ARIA roles: `role="dialog"`, `role="tab"`, `role="combobox"`
- Never add redundant roles to native elements: `<button role="button">` is incorrect

### 3 — Value / State
Dynamic state changes must be reflected in the accessibility tree:

| State | Attribute |
|---|---|
| Expanded / collapsed | `aria-expanded="true/false"` |
| Selected (tabs, options) | `aria-selected="true/false"` |
| Checked | `aria-checked="true/false"` |
| Pressed (toggle button) | `aria-pressed="true/false"` |
| Current page link | `aria-current="page"` |
| Disabled | `aria-disabled="true"` or `disabled` |
| Required | `aria-required="true"` or `required` |
| Invalid | `aria-invalid="true"` |
| Hidden from AT | `aria-hidden="true"` |

## Passes when
- All interactive elements have an accessible name
- All custom widgets use correct ARIA roles
- All dynamic states are reflected in ARIA attributes when they change

## Fails when
- Icon button has no `aria-label` and no text content
- Custom modal is a `<div>` without `role="dialog"` and `aria-modal="true"`
- Toggle button changes visually but `aria-expanded` or `aria-pressed` is not updated
- `aria-labelledby` references an ID that does not exist in the DOM
- `aria-hidden="true"` applied to a focusable element

## Code examples

```html
<!-- Icon button: name from aria-label -->
<button type="button" aria-label="Close dialog">
  <svg aria-hidden="true" focusable="false">...</svg>
</button>

<!-- Expandable section: state via aria-expanded -->
<button aria-expanded="false" aria-controls="details">Show details</button>
<div id="details" hidden>...</div>

<!-- Custom checkbox: role + state -->
<div role="checkbox" aria-checked="false" tabindex="0">
  Subscribe to newsletter
</div>

<!-- Invalid input -->
<input aria-invalid="true" aria-describedby="email-error">
<span id="email-error">Enter a valid email address</span>
```
