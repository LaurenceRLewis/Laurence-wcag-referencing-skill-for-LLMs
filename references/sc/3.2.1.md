# SC 3.2.1 — On Focus (Level A)

## Intent
Receiving keyboard or pointer focus does not automatically trigger a context change — so users are not disoriented by unexpected navigation or content changes when moving between elements.

## What is a context change?
A major change that, if unexpected, can disorient users who cannot see the whole page:
- Opening a new window or tab
- Moving focus to a different component
- Submitting a form
- Significantly rearranging page content

## Passes when
- Focusing a dropdown opens it ready for input without submitting or navigating
- Focusing a link highlights it without following it
- A tooltip appearing on focus is acceptable — not a context change

## Fails when
- Focusing a `<select>` element causes the form to submit immediately
- Focusing a navigation link opens a new browser window without warning
- Focusing a menu item navigates to a page

## WCAG 2.2 change
No change from WCAG 2.1.
