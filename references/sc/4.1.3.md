# SC 4.1.3 — Status Messages (Level AA)

## Intent
Status messages that are not given focus can be programmatically determined through role or property so assistive technologies can announce them to users without requiring focus to move to the message.

## Applies to
Success messages, error summaries, loading indicators, search result counts, cart update notifications, form validation feedback — any dynamic message that appears without focus being moved to it.

## Live region roles

| Role / attribute | Politeness | Use for |
|---|---|---|
| `role="alert"` | Assertive — interrupts immediately | Errors, critical warnings, time-sensitive |
| `role="status"` | Polite — waits for current speech to finish | Success messages, counts, loading complete |
| `aria-live="polite"` | Polite | Dynamic informational updates |
| `aria-live="assertive"` | Assertive | Use sparingly — only truly urgent content |
| `role="log"` | Polite | Appended content (chat log, activity feed) |

## Passes when
- "Changes saved" message uses `role="status"`
- Form error summary uses `role="alert"`
- "3 results found" search result count uses `role="status"` or `aria-live="polite"`
- Loading complete notification uses `role="status"`

## Fails when
- A "Changes saved" message appears in a plain `<div>` with no live region role
- An error summary appears after form submission with no `role="alert"` and focus not moved to it

## Critical implementation rule
Inject content *into* an already-rendered live region — do not inject the live region element itself dynamically. The live region must exist in the DOM before content is added to it.

```html
<!-- Correct: region exists, content injected -->
<div role="status" aria-live="polite" aria-atomic="true" id="save-msg"></div>

<script>
  document.getElementById('save-msg').textContent = 'Changes saved.';
</script>

<!-- Incorrect: region injected dynamically (may not announce) -->
<script>
  const el = document.createElement('div');
  el.setAttribute('role', 'status');
  el.textContent = 'Changes saved.';
  document.body.appendChild(el);
</script>
```
