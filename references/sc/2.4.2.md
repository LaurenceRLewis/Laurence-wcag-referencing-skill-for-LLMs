# SC 2.4.2 — Page Titled (Level A)

## Intent
Web pages have titles that describe their topic or purpose — so users can identify the page without reading all the content, especially useful when multiple tabs are open.

## Passes when
- `<title>` element is present and non-empty
- Title is unique and descriptive across the site
- Title describes the page purpose (e.g. "Checkout — Acme Shop", "Contact Us — City Council")

## Fails when
- `<title>` element is missing
- `<title>` is empty
- `<title>` is generic ("Page", "Untitled", "Home") on non-homepage pages
- All pages share the same title

## Best practice
Format: "Page Name — Site Name" so screen reader users hear the unique page name first.

```html
<title>Contact Us — Acme Corporation</title>
```

## WCAG 2.2 change
No change from WCAG 2.1.
